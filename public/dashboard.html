Definitions and caveats
  • Sessions: GA4 sessions from all channels whose landing page is under /sports-cards/. Nearly all of this traffic comes from search, so there is no separate organic figure.
  • Exit-click sessions: the GA4 exit_click_goal key event, which GA4 counts once per session, credited to the page the session landed on. So the number is sessions that started on that page and included an exit click, not total clicks. It is a stand-in for conversions: it does not show whether the visitor then signed up or bought anything with the brand. Exit-click rate is exit-click sessions divided by sessions.
  • Search clicks, impressions, position and click-through rate: Google Search Console, web search only. Totals are the sum of the page rows, so they can differ slightly from the Search Console screen.
  • Previous period: the same number of days ending the day before your start date (—). Everything marked "Prev" and "Change" compares to it. "new" means there was nothing in the previous period, which is common for pages that launched recently.
  • Pages: each landing URL is matched to a page by its path (for example /sports-cards/apps is Apps, /sports-cards/trove is Trove). Anything under /sports-cards that matches no listed page appears under "Other /sports-cards pages", so the rows always add up to the All view. The page list lives in the project's config file, and new pages (promos, for example) are added there.
  • Left out: /sports-cards/templates/general.php, a template URL that redirects to the homepage, is excluded from every number.
  • Newer pages: Packz, Courtyard, Tilt Rips and Arena Club are new or low-traffic, so their counts are small and their changes are noisy.
  • Search queries: up to the top 25,000 query and page combinations Google returns per period are used, so the table covers the biggest queries well but can miss rare ones on smaller pages. Each query is listed once per landing page it reached. Anonymized queries are not listed.
  • Window: — Search Console data lags about two days, so the latest end date you can pick is two days ago. Ranges of 21 days or fewer are charted by day, longer ranges by week counted from your start date.
